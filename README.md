# AirView 园区无线数字孪生示例

可直接在浏览器中打开 `dist/index.html`，不依赖外部脚本、地图服务或联网资源。

## 使用

新增地球 → 上海 → 园区的连续尺度导航。首次打开显示球形地球；点击上海标记或“聚焦园区”平滑进入原有场景。滚轮、加减按钮及缩放滑杆均可连续缩放，拉远可返回地球。“地球 / 上海 / 青岚科技园”提供快捷视角，地球视角拖动旋转；园区视角直接拖动平移，Shift + 拖动或右键拖动旋转，旋转按钮继续可用。触屏单指平移园区、双指缩放。平移以当前缩放和旋转角度换算，中心限制在园区范围内；“恢复视角”回到园区中央。聚焦画布后可用方向键平移园区、加减键缩放、Home 返回地球、Escape 中止飞行。

假设园区位于上海 WGS84 经度 121.6000° E、纬度 31.2000° N。这个坐标仅作地理锚点，不声称当地真实存在青岚科技园或页面中的建筑、道路与设备。远景地球使用 NASA Blue Marble 2004 年 5 月的历史合成影像；放大后连续保留全球影像的配色和质感，并通过 Natural Earth 海岸线及轻微程序化材质逐渐形成示意底图，再进入合成园区。此风格过渡统一用于全球，未新增上海高分辨率影像；近景材质不代表真实地貌细节。不包含上海真实街道、园区实景影像或测绘地形。相机尺度和 MAC 仿真状态独立，飞行不会重置队列、时间或选中终端。

园区采用本地打包的 Three.js 渲染三维建筑、窗格、屋顶设备和光伏板，并加入日光、阴影、绿化、路缘石、斑马线、停车位与车辆。建筑主体轮廓、高度和 UE 位置取自同一个仿真模型。道路细节、树木及停放车辆仅用于视觉表现，不额外参与遮挡计算；日光是固定的示意光照，不代表实时气象。热力图默认关闭，可从场景图层开启。WebGL 不可用时回退为原有 Canvas 兼容场景。

最大放大倍率已从园区标准视角的 2.378× 提升至 4.757×（原上限的两倍）。选择「室内覆盖」可查看总部 2/3 层及二厂 1 层的移动/静止终端；UE-09/11 移动，UE-10/12 静止。点击「定位终端」将所选位置居中，开启「室内透视」显示所在楼层平面与路线，透视不会影响仿真损耗。gNB-01 和 gNB-02 分别安装在总部大楼和二厂屋顶，高度 110 m 与 58 m。

选择园区漫游、厂房遮挡或办公区拥塞；点击地图中的终端或通过终端选择框查看链路。修改遮挡、业务负载、发射功率和调度策略，观察 MAC 队列、吞吐量、资源分配及 HARQ 事件。支持上下行、暂停、0.5 ms 单步、加速、场景旋转和缩放。

上下行切换、场景切换和重置均会清空统计，重置保留当前实验参数。指标按仿真时间每秒刷新；事件抽样显示，不是完整协议日志。UL 发射功率固定为 23 dBm，基站功率滑块主要影响 DL；覆盖热力图始终表示基站参考信号的近似接收功率。

## 模型

- 1,000 × 1,000 m 合成园区、2 个基站、8 栋建筑、12 个终端（8 个室外、4 个室内）。
- WebGL 三维场景及 Canvas 信息覆盖层；位置、建筑相交、链路、数据流和无线指标使用相同状态。
- 三维距离与建筑体相交判定；其他建筑每栋 16 dB，室内目标建筑 12 dB 外墙 + 0.35 dB/m 室内进深，未模拟楼板/室内隔墙；同频干扰为抽象近似，未采用射线追踪。
- 20 MHz、30 kHz SCS、每小区 51 PRB；0.5 ms 时隙，3 PRB 资源组。
- PF、RR、最大信道质量三种演示调度器；CQI、MCS、传输块大小均近似。
- 发送队列、8 个 HARQ 进程、4 ms 反馈、最多发送 4 次；重传保留原传输块及资源大小，合并增益用递减错误概率近似。
- UL 使用 10 ms 周期缓冲区报告与授权；未实现 SR、随机接入、完整 LCP、真实 TDD 时序及 NR 全栈。
- 小区关联使用 3 dB 迟滞与 500 ms 触发，切换时在途数据回到发送队列；仅用于移动性示意。
- MAC 时延为流体队列等待估计 + HARQ 交付时间，非实测时延或端到端时延。

基于确定性随机种子 2026，可比较相同设置的重复实验。当前为仿真驱动的孪生原型，尚未完成真实系统数据同步与模型校准，不可用作工程覆盖验收。

术语参考：[3GPP TS 38.321](https://portal.3gpp.org/desktopmodules/Specifications/SpecificationDetails.aspx?specificationId=3194)。

## 文件

- `dist/index.html`：页面与模型说明。
- `dist/style.css`：响应式布局。
- `dist/simulation.js`：可独立运行的系统级 MAC 仿真模型。
- `dist/app.js`：场景绘制、交互、状态视图及可选 WebMCP 接口。
- `dist/imagery.js`：统一全球的影像风格渐变与球面反投影，近景为纹理化示意。
- `dist/realistic.js`：日光三维园区及纹理地球；仅负责显示，不改动 MAC 模型。
- `dist/assets/earth-blue-marble-may.jpg`：NASA 历史地表纹理，来源见 `dist/vendor/NOTICE.txt`。
- `tests/simulation.test.cjs`：数据量守恒、资源限制、确定性及场景因果关系检查。
- `dist/globe.js`、`dist/globe.css`：球形地球、地理锚点、层级过渡及交互。
- `dist/geo-data.js`：简化全球与上海地区海岸线；来源与许可证见 `dist/vendor/NOTICE.txt`。
- `tests/globe.test.cjs`：地图与场景的米制尺度连续性、球面多边形、上海定位及缩放边界检查。

运行检查：`node tests/simulation.test.cjs`。

地球导航检查：`node tests/globe.test.cjs`。

下一阶段可将 `simulation.js` 的合成输入替换为带时间戳的真实 UE 位置、调度授权、CQI、BSR、HARQ 和吞吐量数据，再保留同一套场景与 MAC 观察器。
