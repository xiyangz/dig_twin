# AirView 园区无线数字孪生示例

可直接在浏览器中打开 `dist/index.html`，不依赖外部脚本、地图服务或联网资源。

## 使用

选择园区漫游、厂房遮挡或办公区拥塞；点击地图中的终端或通过终端选择框查看链路。修改遮挡、业务负载、发射功率和调度策略，观察 MAC 队列、吞吐量、资源分配及 HARQ 事件。支持上下行、暂停、0.5 ms 单步、加速、场景旋转和缩放。

上下行切换、场景切换和重置均会清空统计，重置保留当前实验参数。指标按仿真时间每秒刷新；事件抽样显示，不是完整协议日志。UL 发射功率固定为 23 dBm，基站功率滑块主要影响 DL；覆盖热力图始终表示基站参考信号的近似接收功率。

## 模型

- 1,000 × 1,000 m 合成园区、2 个基站、8 栋建筑、12 个终端。
- Canvas 2.5D 场景；位置、建筑相交、链路、数据流和无线指标使用相同状态。
- 简化距离损耗 + 每栋 16 dB 遮挡；同频干扰为抽象近似，未采用射线追踪。
- 20 MHz、30 kHz SCS、每小区 51 PRB；0.5 ms 时隙，3 PRB 资源组。
- PF、RR、最大信道质量三种演示调度器；CQI、MCS、传输块大小均近似。
- 发送队列、8 个 HARQ 进程、4 ms 反馈、最多发送 4 次；重传保留原传输块及资源大小，合并增益用递减错误概率近似。
- UL 使用 10 ms 周期缓冲区报告与授权；未实现 SR、随机接入、完整 LCP、真实 TDD 时序及 NR 全栈。
- 小区关联使用 3 dB 迟滞与 500 ms 触发，切换时在途数据回到发送队列；仅用于移动性示意。
- MAC 时延为流体队列等待估计 + HARQ 交付时间，非实测时延或端到端时延。

基于确定性随机种子 2026，可比较相同设置的重复实验。当前为仿真驱动的孪生原型，尚未完成真实系统数据同步与模型校准，不可用作工程覆盖验收。

术语参考：[3GPP TS 38.321](https://portal.3gpp.org/desktopmodules/Specifications/SpecificationDetails.aspx?specificationId=3194)。

## 文件

- `dist/index.html`：页面与模型说明。
- `dist/style.css`：响应式布局。
- `dist/simulation.js`：可独立运行的系统级 MAC 仿真模型。
- `dist/app.js`：场景绘制、交互、状态视图及可选 WebMCP 接口。
- `tests/simulation.test.cjs`：数据量守恒、资源限制、确定性及场景因果关系检查。

运行检查：`node tests/simulation.test.cjs`。

下一阶段可将 `simulation.js` 的合成输入替换为带时间戳的真实 UE 位置、调度授权、CQI、BSR、HARQ 和吞吐量数据，再保留同一套场景与 MAC 观察器。
